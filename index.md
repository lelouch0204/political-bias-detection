## 🎯 Project Overview

<div class="info-box">

This repository contains our comprehensive machine learning project for **CS 7641 - Machine Learning**. We are developing and implementing state-of-the-art ML algorithms to detect political bias in piece of text.

</div>

### Key Objectives
- Implement and compare multiple ML algorithms
- Conduct thorough data preprocessing and feature engineering
- Evaluate model performance using various metrics
- Provide insights on algorithm effectiveness and real-world applicability
